# 🎲 DnD Book QA Bot  

Этот Telegram-бот отвечает на вопросы по книге "Книга Игрока", помогая игрокам Dungeons & Dragons быстро находить нужную информацию.  

## ✨ Возможности  
- Принимает текстовый вопрос от пользователя.  
- Находит релевантные ответы в книге и возвращает их в удобном виде.  
- Поддерживает естественный язык — не нужно формулировать вопрос строго по содержанию книги.  

## 🔮 Для чего может пригодиться  
- Игрокам — чтобы быстро уточнять правила во время сессии.  
- Мастерам — как справочник под рукой.  
- Всем, кто хочет изучать книгу интерактивно, в формате диалога.
